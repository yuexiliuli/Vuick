# 快捷键

编辑区内查找的 `F3` / `Shift+F3` / `Esc` 键位也在此表（按 `Ctrl+F` 打开查找卡后使用）。

| 按键 | 作用 |
| --- | --- |
| `Ctrl+N` | 新建选项卡 |
| `Ctrl+O` | 打开文件（系统对话框） |
| `Ctrl+Shift+O` | 打开文件夹（侧栏文件树） |
| `Ctrl+W` | 关闭当前选项卡 |
| `Ctrl+S` | 保存（未命名时弹保存对话框） |
| `Shift+Ctrl+S` | 另存为 |
| `Ctrl+P` | 打开文件快选（工作区模糊检索，500 上限） |
| `Ctrl+Shift+P` | 命令面板 |
| `Ctrl+F` | 编辑区内查找（只读高亮，`F3` / `Shift+F3` 上一个 / 下一个，`Esc` 清除） |
| `Ctrl+G` | 跳转到行（实时，支持 `行:列`） |
| `Ctrl+M` | 音乐播放器开关 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 增大 / 减小 / 重置字号 |
| `Ctrl+C` / `Ctrl+V` / `Ctrl+X` | 复制 / 粘贴 / 剪切 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+A` | 全选 |
| `← → ↑ ↓`（可加 `Shift` / `Ctrl` / `Alt`） | 光标移动 / 选择 / 词级与文档级导航 |
| `Backspace` / `Delete`（可加 `Ctrl`） | 删除上一个 / 下一个词 |
| `Ctrl+Q` | 退出 |
